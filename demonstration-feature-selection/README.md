# Demonstration and feature selection

Automatic selection of good demonstrations and relevant features with Dissimilarity Mapping
Filtering (DMF), so that the robot learns only from consistent examples.

Publication: S. Morante, J. G. Victores and C. Balaguer, "Automatic demonstration and feature
selection for robot learning", *Humanoids 2015*, pp. 428-433.
[doi:10.1109/HUMANOIDS.2015.7363569](https://doi.org/10.1109/HUMANOIDS.2015.7363569)

This folder is also maintained, with tests and as an installable package, in
[dissimilarity-mapping-filtering](https://github.com/Morante-tech/dissimilarity-mapping-filtering).

## Contents

| Folder | Content |
|---|---|
| `src/` | Demonstration selector, feature selector, viewers and two alternative approaches. See the [README of dissimilarity-mapping-filtering/python](https://github.com/Morante-tech/dissimilarity-mapping-filtering/tree/main/python) |
| `datasets/experiment-1/` | 10 demonstrations and the ones selected with each configuration ([format](datasets/experiment-1/README.md)) |
