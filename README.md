# Connected images

##About
Algorithms to connect movements between images. We are currently developing two concepts at the same time. One is a standard feedforward fully connected artificial neural network. The other is a custom network with an, also custom, error function. We compare actual images or images variations (until we decide which method is the best).


### Organization
* In `cross-validation` folder you can find all the data related to the experiments.

* In `feed` folder there are several videos to be used during development as example video files.

* In `src` folder you can find the source code, both python and c++ versions.

* In `video-execution` folder you can find some videos showing the execution of the code.

## Performance 
The best performance, in quality, currently corresponds to: python neural network.
