# Connected images

*Abandoned project.*

## About
Algorithms to connect movements between images. One is a standard feedforward fully connected artificial neural network. The other is a own motion network. We compare actual images or images variations (until we decide which method is the best).


### Organization
* In `cross-validation` folder you can find the description of the experiments and the scripts used to analyse them.

* In `src` folder you can find the source code, both python and c++ versions.

* In `raws` folder you can find the description of the raw recordings.

The videos, the synthetic examples and the trained networks were removed from the repository
history in 2026 to keep it small, so the experiments cannot be reproduced from this repository.
